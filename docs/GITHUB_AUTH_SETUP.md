## 2. Choose ONE authentication method

Pick exactly one. Mixing methods is the most common cause of confusing
"works in one terminal, fails in another" failures.

### Option A — GitHub CLI (recommended for this project)

Best when you also want `gh` for opening pull requests.

```
winget install --id GitHub.cli
gh auth login
```

Choose, when prompted:
- GitHub.com
- HTTPS
- Login with a web browser (safest — no token is ever typed into a terminal)

Verify:

```
gh auth status
```

Expected output contains something like `Logged in to github.com account <you>`.
`gh auth login` stores the credential in the Windows Credential Manager, not
in this repository.

### Option B — HTTPS + Git Credential Manager (recommended fallback)

Already installed. You only need a remote URL and a one-time browser login.

```
git remote add origin https://github.com/<owner>/<repo>.git
git fetch origin
```

Git Credential Manager opens a browser window, you authorise it, and the
credential is stored in the Windows Credential Manager. It is never written
to disk inside the repository and never appears in `.git/config`.

### Option C — SSH

Best for a long-lived, key-based setup with no repeated prompts.

```
ssh-keygen -t ed25519 -C "your-github-account"
type $env:USERPROFILE\.ssh\id_ed25519.pub
```

Copy the printed **public** key into GitHub → Settings → SSH and GPG keys.
Then:

```
ssh -T git@github.com
```

If that prints a greeting containing your username, SSH auth works. Add the
remote as:

```
git remote add origin git@github.com:<owner>/<repo>.git
```

The **private** key (`id_ed25519`, no extension) must never be copied into
this repository, a chat, or a script file.

## 3. Create the remote repository

If no repository exists on GitHub yet:

1. Open https://github.com/new
2. Name it (for example `hermes-android`)
3. Choose **Public** or **Private** as appropriate
4. **Do not** tick "Add a README", `.gitignore`, or licence — this
   repository already has history and adding those causes a divergence that
   must be resolved by hand
5. Create it

Then connect it:

```
git remote add origin https://github.com/<owner>/<repo>.git
```

Replace `<owner>` and `<repo>` with the real values. Do not hardcode them in
any script in `scripts/`.


## 4. Known credential-helper concern on this machine

`git config --global --list` shows a per-user `credential.helper` entry that
**overrides** the system Git Credential Manager helper with a custom shell
function which supplies a token from an environment variable.

What this means in practice:

- The system-level `credential.helper=manager` is *disabled* for this user.
- Git operations depend on that environment variable being present in the
  shell that launches Git. A new terminal, a scheduled task, or an IDE-launched
  Git may not have it, producing intermittent "could not read Username"
  or "repository not found" errors.
- The token itself is not in this repository, so it is not exposed in Git
  history. That is the good news. The risk is *reliability and scope*, not
  exposure.

Recommended owner action, if a clean, standard setup is wanted:

```
git config --global --unset credential.helper
```

…then re-authenticate using Option A or B above. This removes the
dependency on an out-of-band environment variable. **Only do this if you are
certain you have another way to authenticate**, otherwise you may lock
yourself out of the remote.

If the existing helper is intentional (for example, a setup that injects
`GITHUB_TOKEN`), leave it in place and simply be aware that authentication is
environment-dependent.

## 5. Configure commit identity (required before any commit)

`user.name` and `user.email` are currently unset, so **every commit will
fail**. This is required even for purely local work.

```
git config user.name  "Your Name"
git config user.email "you@example.com"
```

Use the same email address that is registered on your GitHub account, or
GitHub will not link the commits to your profile. To make this the default
for every repository on this machine, add `--global`.

Verify:

```
git config user.name
git config user.email
```
